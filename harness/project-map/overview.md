# Project Overview

## 项目名称

AI Project Notebook

## 一句话描述

面向 AI 辅助开发的命令行项目理解与知识沉淀工作台。

## 当前版本

v0.1 — 最小命令行版本

## 核心概念

- **项目地图 (project-map/)** — 项目的结构化知识库，包含目录、模块、命令、数据流、变更记录
- **规则 (rules/)** — 可执行的开发约束，不是建议而是必须遵守的操作步骤
- **反馈 (feedback/)** — 从错误和改进中沉淀的经验，驱动规则演化
- **脚本 (scripts/)** — 自动化检查与维护工具
- **技能 (skills/)** — AI Agent 可用的工作流技能定义
